# EmberLife: Personal Health Monitor for Long-Duration Missions

NASA Space Apps Challenge 2026 project (solo entry).

## The challenge
Long-duration missions expose astronauts to radiation, isolation and confinement, altered gravity and a closed environment, which can cause immune changes, bone loss, cardiovascular events and behavioral health problems. Astronauts carry much of the responsibility for spotting these changes in themselves.

## What EmberLife does
- **Daily check-in:** the astronaut logs sleep hours, resting heart rate and mood.
- **Personal baseline:** the first 14 days set that astronaut's own normal.
- **Deviation score:** the last 7 days are compared with the baseline, in standard deviations.
- **Status cards:** red, yellow or green per indicator.
- **Trend charts** make slow changes visible.
- **Recommended actions** suggest next steps, such as contacting the flight surgeon.

## Run it
```
pip install -r requirements.txt
python main.py        # generates simulated health_data.csv
streamlit run app.py
```

## Files
- `main.py`: generates 90 days of simulated health data
- `app.py`: the Streamlit dashboard
- `health_data.csv`: simulated dataset

## Data
The prototype uses **simulated data**, generated by `main.py`. It is not real astronaut data.
